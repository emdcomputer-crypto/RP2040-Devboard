# RP2040 Devboard

This repository is the starting point for my Week 5 Half Life project: a custom RP2040 development board, based on the guided Devboard project.

## Project files

- `Hardware/` — KiCad schematic and PCB design files.
- `FabricationFiles/` — manufacturing and assembly outputs.
- `Firmware/` — firmware and board bring-up files.
- `Pictures/` — project photos and design images.
- `BOM.csv` — bill of materials.

Project files will be added as the design progresses.
